# 产品最终方案：两个主功能 + 三层底座

> 2026-10-18 ｜ 本文替代 `FEATURE_DESIGN.md` 的功能清单部分，为最终实施依据
> 依据：29 个交易日真实存档、5,485 只股票日线、四轮量化检验

---

## 一、产品定位（一句话）

> **每天告诉你两件事：今天买什么（带理由和持有期），以及你手里的该怎么动（理由还在不在）。**

只有两件事。其余全是支撑这两件事的底座。

---

## 二、整体结构

```
┌─────────────────────────────────────────────────────────┐
│  ① 今天能不能做？        ← 市场状态开关（底座1）           │
│     可做 / 观望   ·   建议仓位 40%  ·   实际暴露 40%       │
├─────────────────────────────────────────────────────────┤
│  ② 买什么（主功能 A）                                     │
│     3~5 只，每只带：为什么买 / 历史胜率 / 持有几天 /        │
│     净收益预期（扣成本）/ 参考支撑压力 / 该配多少仓         │
├─────────────────────────────────────────────────────────┤
│  ③ 手里的怎么办（主功能 B）                                │
│     4 只，每只带：买入理由还在吗 / 该持有还是减仓 / 风险     │
├─────────────────────────────────────────────────────────┤
│  ④ 系统准不准（底座2）                                    │
│     近30天：建议62笔，5日胜率55%，净+0.9%/笔，尚未显著      │
└─────────────────────────────────────────────────────────┘
     底座3：成本与风控 —— 每笔都算净收益、卡仓位上限
```

**一屏看完。** 涨停池、龙虎榜、RSI 扫描、资金流这些都保留，但降级为"点进去才看"的辅助数据，不占主界面。

## 三、主功能 A：买什么

### 3.1 三个模式的实测表现（决定模式怎么定）

样本外 15 天，扣往返成本 0.202%：

| 模式 | 持有期 | 胜率 | 毛收益 | **净收益** | 结论 |
|---|---|---|---|---|---|
| 短线 | T+1 | 48.6% | +0.13% | **−0.07%** | ❌ 亏损 |
| | T+3 | 46.2% | +0.08% | **−0.12%** | ❌ 亏损 |
| **波段** | **T+5** | **55.0%** | **+1.35%** | **+1.15%** | ✅ **最优** |
| 长线 | T+10 | 48.5% | +0.72% | **+0.52%** | ✅ 有效但弱 |

**三个模式保留，但定位调整：**
- **波段（T+5）= 主力模式**，也是默认模式
- **长线（T+10）= 次选**，适合没时间天天看盘
- **短线（T+1/T+3）= 保留但明确警示**："本模式期望净收益为负，除非你的佣金低于万分之一"

> **这是最关键的一条产品建议：不要鼓励短线。** 0.202% 的往返成本会吃掉全部优势。
> 你越频繁交易，亏得越多 —— 这是数据说的，不是我的偏好。

### 3.2 选股逻辑必须翻转方向

现状是"追强势"，实测是反向的（T+5 口径）：

| 指标 | 现状用法 | 实测方向 | t 值 |
|---|---|---|---|
| 距 MA10 | 越远越好 | **越近越好** | **−15.67** |
| 连板数 | 忽略 | **越高越好** | **+13.62** |
| 距 MA20 | 越远越好 | **越近越好** | −12.24 |
| 距 20 日高 | 越近越好 | **越远越好** | −10.76 |
| 距 20 日低 | — | 越远越好 | −8.83 |
| RSI6 | 越高越好 | **越低越好** | −6.51 |

**采样外验证（翻转后）：T+5 胜率 55.0%、均 +1.35%、盈亏比 1.76**（现状排序是 35.5% / −1.33% / 0.61）。

### 3.3 每只股票要展示什么

```
600xxx  XX股份              波段模式 · 建议持有 5 天
─────────────────────────────────────────────────
【为什么选它】
  距 MA10   +1.2%   历史分位 35%  ✅偏低（好）
  距 20日高  −8.4%   历史分位 28%  ✅远离高点（好）
  距 MA20   +3.1%   历史分位 45%  ✅中性偏好
  RSI6      58.2    历史分位 42%  ✅中性偏好
  连板数     2       ✅有资金关注

【历史同类表现】  ← 这是"可信度"
  条件：距MA10 0~3% 且 RSI6 55-65
  样本：1,240 次 / 22 个交易日
  5日胜率 55.0%   平均 +1.3%   盈亏比 1.76
  扣成本后预期 **+1.1%**

【怎么做】
  建议仓位 8%（按单笔亏损不超过总资金 1% 反推）
  参考支撑 10.02（MA10，跌破=买入理由消失）
  参考压力 11.30（20日高下方3%）
  ⚠ 明日若开盘跳空 >+2%，等回踩，别追

【风险提示】
  同行业已持有 2 只（占比 41%）⚠ 注意集中度
```

**三个必备要素**（现在的界面都没有）：
1. **历史同类胜率 + 样本量** —— 让你知道这个建议有多可信
2. **扣成本后的净收益** —— 让你知道值不值得做
3. **买入理由** —— 为功能 B 服务

### 3.4 一天给几只？

**3~5 只。** 理由：
- 现在的 800~1600 只，任何"精选"都等于没选
- 实测每天取前 20 才有统计意义，但个人资金分散到 20 只没意义
- 3~5 只 + 明确仓位，才是可执行的

## 四、主功能 B：手里的怎么办

### 4.1 核心思路：不是止损止盈，而是「买入理由还在吗」

这是我认为**比止损止盈更进一步**的设计。原因：

止损止盈只回答"价格到了没"，但真正让人亏钱的是 —— **当初买它的理由已经消失了，你还在拿着。**

例：你因为"回调到 MA10 附近"买入，现在它涨到 MA10 上方 8.6%，RSI 从 58 涨到 72。
**买入理由（便宜的回调）已经消失，变成了"追高"** —— 这时候该减仓，但价格还没跌破任何止损线，你不会有任何感觉。

### 4.2 每只持仓要展示什么

```
600xxx  XX股份    持仓 3 天    成本 10.50 → 现价 10.82   +3.05%
─────────────────────────────────────────────────────────
【买入理由检查】  ← 核心
  当初理由：接近 MA10（+1.2%），RSI6 58
  现在    ：距 MA10 +8.6%，RSI6 72.4
  结论    ：⚠ **理由已消失**（回调买点变成了追高）

【技术状态】
  在 MA20 上方          ✅
  未跌破 ATR 止损 10.18  ✅
  相对行业 +1.2%         ✅ 略强

【建议动作】  ⚠ 减仓 50%
  理由：买入理由消失，但趋势未破 → 留一半观察
  剩余仓位止损上移至 10.60（保本）

【风险】
  占总仓位 18%
  同行业已持 2 只（41%）⚠ 偏高
  明日跌破 MA10（10.02）→ 全部清出
```

### 4.3 四种动作的判定规则（规则化，不靠猜）

| 动作 | 触发条件 |
|---|---|
| **继续持有** | 买入理由仍成立 + 趋势未破（在 MA20 上方） |
| **减仓** | 买入理由消失（偏离买入位超阈值）+ 趋势未破 |
| **清仓** | 趋势破坏（跌破 MA20）**或** 跌破 ATR 止损 |
| **加仓** | 理由更充分（回到买入位附近）+ 仓位未超限 |

**关键：这些规则必须写成代码，输出可复现的理由，不能是"AI 感觉"。**

### 4.4 提醒（PWA 推送或每日摘要）

- 触及止损 / 目标
- **持有期到了**（波段 5 天到期必须决策，不能拖成长期股东）
- 买入理由消失
- 行业集中度超限

## 五、三层底座

### 底座 1：市场状态开关（决定 A 出不出名单）

实测：α 只存在于跌市

| 市场状态 | 天数 | α | α>0 天数占比 |
|---|---|---|---|
| 涨市 | 16 | +0.026% | 31%（**69% 跑输**） |
| 跌市 | 12 | **+0.218%** | 58% |

**用法**：
- 跌市 → 正常出名单（有优势）
- 涨市 → 提示"本系统在上涨市跑输概率 69%，建议减半仓位或直接买指数"
- 极端退潮 → "今天建议观望，不出名单"

### 底座 2：验证层（让它可信）

**每一个建议、每一个信号、每一个指标，都必须带样本量和置信度。**

```
✅ 可靠：距MA10 分位（t=−15.67, 样本 26,526）
⚪ 无定论：龙头信号（t=−1.97, 样本 872）
⚠️ 无效：题材信号（t=−0.82, 样本 11,309）—— 不要用它做决策
```

**同时系统要能自证**：
```
系统近况（近 30 个交易日）
  建议 62 笔：5日胜率 55%，净 +0.9%/笔
  ⚠ 样本不足（<250 天），结论仅供参考
```

**这一条是防止你被模型带偏的关键。** 现在系统展示"命中率 72.9%"，但那是回测值，实盘 7 次是 28%~72% 波动。

### 底座 3：成本与风控（决定买多少、值不值得）

| 项 | 数值 |
|---|---|
| 佣金 | 0.025% × 2 |
| 印花税 | 0.05%（卖出） |
| 过户费 | 0.001% × 2 |
| 滑点 | 0.10%（开盘价成交） |
| **往返合计** | **0.202%** |

**每个建议都必须显示净收益，而不是毛收益。**

风控硬约束：
- 单笔最大亏损 ≤ 总资金 1% → 反推仓位
- 单票 ≤ 总资金 20%
- 同行业 ≤ 3 只

## 六、数据基础：需要新建什么

| 表 | 用途 | 优先级 |
|---|---|---|
| **`trades`**（买入/卖出记录） | 功能 B 的前提：成本、买入日期、**买入理由** | **P0** |
| `watchlist`（已有） | 关注 | — |
| `recommendation_log`（已有 forecast_history） | 记录每次建议的指标快照，供事后验证 | P0（需补字段） |
| `signal_stats`（已有 sm:signal_weights） | 信号/指标有效性 | 已有 |

**最关键的是 `trades` 表**：没有它，功能 B 根本无法工作（不知道你买了什么、成本多少、为什么买）。

```
trades:
  id, code, name, direction(buy/sell), price, shares,
  trade_date, hold_days,
  reason_json     ← 买入时的指标快照（距MA10、RSI、信号…）
  reason_src      ← 来自哪条建议（推荐ID）
  pnl, created
```

**买入理由快照是功能 B 的灵魂。** 有了它才能回答"理由还在吗"。

## 七、分阶段实施

| 阶段 | 内容 | 工期 | 验收标准 |
|---|---|---|---|
| **P0** | ① 选股方向翻转（后端打分）<br>② `trades` 表 + 买入记录<br>③ 每只带「历史同类胜率+样本量」 | 3 天 | 名单方向改变；能记录买入 |
| **P1** | ④ 市场状态开关（出/不出名单）<br>⑤ 净收益 = 毛收益 − 成本<br>⑥ 仓位计算（按 1% 风险反推） | 3 天 | 每个建议都有净收益和仓位 |
| **P2** | ⑦ **持仓分析**（买入理由检查 + 4 种动作建议）<br>⑧ 提醒（止损/到期/理由消失） | 4 天 | 每只持仓有明确动作建议 |
| **P3** | ⑨ 系统自证面板（近30天真实战绩）<br>⑩ AB 对照：现状 vs 翻转并行跑 | 2 天 | 两周后自动出胜负报告 |
| **P4** | ⑪ 交易复盘（按信号拆解你的个人胜率） | 3 天 | 你能说出自己最差的信号 |

**合计 15 天。**

## 八、我不建议做的（及原因）

| 不做 | 原因 |
|---|---|
| 独立"回测"tab | 口径与实盘不一致（现在前端算的龙头战法，和实盘持有期不同）—— 会误导 |
| `rank_score` 综合分排序 | Rank IC = 0.01，t=1.02，没有信息量 |
| "命中率/胜率"作为主指标 | 不扣成本、不分市场状态，必误导 |
| T+1 高频轮动作为主打 | 扣成本后 −0.07%/天，年化负 |
| 复杂的因子挖掘 | 29 天样本做因子挖掘 = 过拟合。**先把手上的指标用对，比找新因子重要 10 倍** |

## 九、我需要你定三件事

1. **短线模式怎么处理？**
   - A：保留但标红警示（"期望净收益为负"）
   - B：保留并悄悄降权，只在长线/波段没标的时才出
   - C：直接去掉，只留波段+长线
   → **我建议 A**：诚实告知，你自己决定。

2. **买入怎么记？**
   - A：手动记（点"我买了"填成本）
   - B：接券商导出（需要你研究接口）
   - C：只记"我想买"（模拟盘），不对接真实持仓
   → **我建议先 A**，简单可落地。

3. **先做哪个？**
   → **我建议 P0 先做「选股方向翻转」**：改动最小（只改后端打分），1 天可见效果，而且能立刻验证翻转是否真的有效。

## 十、我对"帮我投资"这句话的理解

你说归根到底是帮我投资股票。我认为一个工具能帮的是三件事，按确定性排序：

| 能帮什么 | 确定性 | 怎么做 |
|---|---|---|
| **1. 让你少亏** | ✅ 高 | 成本可视化、仓位上限、行业集中度、跌市提示、不鼓励短线 |
| **2. 让你少犯错** | ✅ 高 | 买入理由检查、到期提醒、规则化动作建议 |
| **3. 让你多赚** | ⚠️ 中 | 指标方向翻转（样本外 +1.15%/笔，但需实盘验证） |

**前两件事现在一件都没做好，而它们比第三件更确定。**

所以我的方案里，风控和纪律占了很大比重 —— 不是因为我保守，而是因为**那是唯一确定能改善结果的部分**。
