# 交易工作台 · 功能设计方案

> 起草 2026-10-18 ｜ 所有结论基于本项目 29 个交易日真实存档 + 5,493 只股票日线实测
> 目标：把「预测选股器」改造成「真正帮交易的决策工作台」

---

## 一、先说结论：为什么现在的功能帮不上你

我用项目自己的历史存档做了 5 项样本外检验，结果如下。

### 1.1 预测池没有选股能力

| 指标 | 实测 |
|---|---|
| 池子日内收益（次日开盘买→当日收盘卖） | **+0.136%** |
| 全市场日内收益（同期同口径） | **+0.110%** |
| **日内 α** | **+0.026% ≈ 0** |
| α 为正的天数 | **6 / 14（43%，接近抛硬币）** |
| 池子收盘−市场收盘 | **−0.059%（负）** |

> 之前"T+1 有 +0.18%"看起来是有效，但那 +0.11% 是**市场本身的日内漂移**，只属于市场。
> 池子贡献的部分只有 0.026%，扣掉手续费（约 0.1%/来回）就是负的。

### 1.2 决定性：信号权重用的是错误的时间口径

信号权重按**次日涨跌**拟合，但用户实际持有 5 天。两种口径下信号效应**负相关 −0.53**：

| 信号 | 现口径(次日) | 实际口径(持有5天) | 结论 |
|---|---|---|---|
| `sig_leader` 龙头 | **+0.69%** | **−0.82%** | **符号相反** |
| `sig_wyckoff` 吸筹 | +0.45% | −0.74% | 符号相反 |
| `sig_volDry` 地量 | −0.31% | **+1.42%** | 符号相反（实为最强） |
| `sig_bollSq` 布林收口 | −0.15% | **+0.91%** | 符号相反（第二强） |
| `sig_value` 价值 | −0.12% | **−0.99%** | 一致（更差） |

**系统把最该买的排在最下面，把最该避开的排在最上面。**

实测排序效果（样本外）：

| 每天取前 N | 现状排序 | 随机 | 全池 |
|---|---|---|---|
| 前 10 | **−1.59%** | −0.87% | |
| 前 20 | −1.33% | −0.66% | |
| 前 50 | −1.26% | −0.07% | |
| 全部 | | | **−0.30%** |

**「精选」是负贡献，选得越少越差，随机都比它好。**

### 1.3 名单太大，注定等于市场
每日输出 **792~2,235 只**，占全市场 **14%~41%**。
这么大的名单在数学上不可能有 alpha —— 它近似就是市场本身。

### 1.4 持有期设计反了
样本外，同一批股票不同持有期：

| 持有期 | 全池 | 随机 |
|---|---|---|
| **T+1** | **+0.18%** | +0.14% |
| T+2 | −0.30% | −0.36% |
| T+3 | −0.76% | −0.33% |
| T+5 | −0.30% | −0.05% |
| T+10 | −1.20% | −0.82% |

**只有 T+1 是正的，之后全负。** 而系统给的是"5 天持有 + 固定 −3% 止损 + 6% 止盈"。

### 1.5 27% 的建议根本买不到
实测 33,027 个候选的次日开盘跳空分布：

| 跳空区间 | 占比 |
|---|---|
| −2% ~ 0% | 30.9% |
| 0% ~ +2% | 24.1% |
| **+3% 以上（按规则放弃）** | **27.0%** |
| +2% ~ +3% | 部分 |

**超过 1/4 的推荐信在第二天开盘就买不到**，而系统从不提示这一点。

### 1.6 止损设置被噪声打掉
实测（30 天 / 22,709 笔）：

| 离场方案 | 胜率 | 均收益 | 盈亏比 | 止损率 |
|---|---|---|---|---|
| A 现状（固定 −3% 止损 / +6% 止盈） | 26.8% | −0.65% | 0.68 | **66%** |
| C 无止损，持 5 天 | **44.4%** | **−0.27%** | **0.90** | 0 |
| E ATR 2× 止损 | 41.1% | −0.56% | 0.80 | 21% |

**A股日均波动约 2.5%，−3% 的固定止损等于把自己交给噪声 —— 66% 的仓位被打掉，而且是先打掉再反弹。**

## 二、根因诊断（三条）

| # | 根因 | 表现 |
|---|---|---|
| 1 | **产品定位错**：卖"选股名单"，但数据证明没有选股能力 | 名单占市场 14~41%，α≈0，精选比随机差 |
| 2 | **度量与交易脱节**：用"次日涨跌"优化，用户却持有 5 天 | 排序反向，信号权重符号错 |
| 3 | **没有反馈闭环**：不知道用户实际做得怎样 | 无法区分"选股不行"还是"执行不行" |

## 三、功能重设计

### 3.1 定位转变

| | 现在 | 改成 |
|---|---|---|
| 定位 | 预测选股器（承诺"买什么"） | **交易决策工作台**（帮你"做对决策、执行到位、复盘改进"） |
| 核心输出 | 1000+ 只股票名单 | **3~8 个可执行动作** + 明确的风险边界 |
| 对选股的表述 | "明日预测" | **"候选池"**（明确不是买入建议） |
| 优势来源 | 选股 alpha（**不成立**） | **信息效率 + 执行纪律 + 反馈闭环**（成立） |

### 3.2 新功能清单（按价值排序）

---

#### 功能 1 ★★★★★ 「今日决策卡」——回答"今天该不该做"

**解决的问题**：现在 7 个 tab 看完仍不知道该不该开仓。

**内容**
```
┌─────────────────────────────────────────┐
│  今天建议：⚠ 观望        （置信度 中）    │
│                                          │
│  理由：池子近 14 天 α 仅 +0.03%，          │
│        且今天环境为「退潮」                │
│                                          │
│  ├ 市场状态：退潮   环境系数 0.5           │
│  ├ 建议仓位：25%（区间 15~35%）           │
│  ├ 实际市场暴露：11%（策略 beta 0.45）     │
│  └ 历史同日型：此类日子池子 α 中位数 −0.1% │
│                                          │
│  [看候选池]   [看我持仓]                  │
└─────────────────────────────────────────┘
```

**数据依据**：α 在 14 天里 6 天为正（43%），**波动极大** → "少做"本身就是有价值的建议。
建议仓位与 beta 换算已有实现（`/api/position-advice`）。

**验收**：每天输出的建议与实际 α 方向的一致性 ≥ 55% 才算上线。

---

#### 功能 2 ★★★★★ 「交易清单」——3~8 只，带可执行条件

**解决的问题**：1500 只名单没有决策价值；且不告诉你能不能买到。

**清单每一条必须包含**

| 字段 | 说明 | 依据 |
|---|---|---|
| 代码/名称/行业 | | |
| **买入触发价** | 不是"系统 entry"，而是**可成交价**：次日开盘价 ±0.5% | 27% 的建议开盘就买不到 |
| **⚠ 买不到预警** | 若次日可能跳空 >+2%，标注"等回踩" | 同上 |
| **预期持有** | **T+1（当日买、次日卖或当日冲高卖）** | 只有 T+1 为正 |
| **退出规则** | 目标价 / 止损价用 **ATR 2×** 而非固定 % | 固定 −3% 止损率 66% |
| **信号正负** | 明确标 ✅正向 / ⚠️负向 | 5 个信号实际符号与展示相反 |
| **建议仓位** | 按风险预算算（单笔最大亏损 ≤ 总资金 1%） | |

**关键设计：清单只从「正向信号 + 可成交 + 非负向扎堆」的候选里选，且最多 8 只。**

**验收**：清单前 8 只的 T+1 收益 ≥ 全池 +0.1%，连续 20 个交易日。

---

#### 功能 3 ★★★★★ 「持仓管家」——现在完全缺失

**解决的问题**：系统只管买，不管卖。而亏损大多来自卖出。

**每只持仓一张卡**

```
┌────────────────────────────────────────┐
│ 600xxx  XX股份        持仓 3 天          │
│  成本 10.50 → 现价 10.82   +3.05%       │
│                                          │
│  ▓▓▓▓▓▓▓░░░░░░░░  距目标 61%            │
│  止损 10.18 ──── 现价 ──── 目标 11.30    │
│                                          │
│  今日建议：继续持有                       │
│    理由：未破 ATR 止损，量比 1.8 正常      │
│                                          │
│  ⚠ 若收盘跌破 10.18 → 次日止损            │
└────────────────────────────────────────┘
```

**必备能力**
- 浮盈亏实时 / 距离止损与目标的进度条
- **今日动作建议**：持有 / 减仓 / 止损 / 止盈（规则化，不靠猜）
- **到期提醒**：T+1 策略到期必须走，不能拖成"长期股东"
- **移动止损**：有盈利后止损上移，锁定收益

**验收**：接入后回测，止损执行率与规则符合度可从 0 提到 >90%。

---

#### 功能 4 ★★★★★ 「交易日志 + 我的胜率」——最大缺口

**解决的问题**：系统能说"买什么"，但**永远无法告诉你"你做得怎么样"**。

**这是提升投资收益最直接的一环。**

**内容**
```
┌── 我的交易复盘 ──────────────────────┐
│  近 30 笔：胜率 42%  平均 +0.8%        │
│                                          │
│  按信号拆解（我的真实战绩）                │
│    龙头信号  12 笔  胜率 25%  ← 别再用    │
│    低吸信号   8 笔  胜率 62%  ← 加权重    │
│    无信号      6 笔  胜率 33%             │
│                                          │
│  对比                                   │
│    vs 系统模拟账户：+0.8% vs -0.3%  ✅    │
│    vs 全市场：      +0.8% vs -0.1%  ✅    │
│                                          │
│  最大问题：平均持有 8 天（建议 T+1）        │
└──────────────────────────────────────────┘
```

**必备能力**
- 每笔交易：代码 / 买入价 / **买入理由（选了哪个信号）** / 卖出价 / 盈亏 / 持有天数
- **按信号维度拆解个人胜率** → 形成**个人化的信号权重**（比模型的通用权重更可靠）
- 我的净值曲线 vs 系统模拟 vs 市场基准
- 行为统计：追高比例、止损执行率、平均持有天数

**验收**：用户能回答"我哪个信号赚钱、我最大的坏习惯是什么"。

---

#### 功能 5 ★★★★ 「买入前检查清单」——用 30 秒避掉常见错误

**现在完全没有**。基于实测数据：

| 检查项 | 判定 | 依据 |
|---|---|---|
| 明天买得到吗 | 预测开盘跳空 >+2% → 提示"等回踩" | 27% 买不到 |
| 负向信号扎堆吗 | 有 ≥2 个负向信号 → 警示 | 价值 −0.99% / 突破 −0.68% |
| 行业太集中吗 | 同行业已有 ≥2 只 → 警示 | 分散原则 |
| 单票超仓位了吗 | 占用 > 总资金 20% → 拦截 | 风控 |
| 大盘状态允许吗 | 退潮期 → 要求减半仓位 | 环境系数 |

**验收**：这 5 项每项都有明确的通过/不通过判定，且不通过时给出替代方案。

---

#### 功能 6 ★★★★ 「信号可信度看板」

**已有基础，但结论要改。**

必须展示**实盘口径**（T+1 或 T+5，与产品持有期一致）的信号效应，并**正负分色**：

```
✅ 正向：地量 +1.42%   布林收口 +0.91%   低吸 +0.71%
⚠️ 负向：价值 −0.99%   龙头 −0.82%   吸筹 −0.74%   突破 −0.68%
   样本：24 个交易日 / 26,000+ 次触发
```

**并且：信号面板要显示样本量。** 样本 < 200 的信号标"样本不足，仅供参考"。

**验收**：任何信号在使用前，用户都能看到它的方向与样本量。

---

#### 功能 7 ★★★ 「事实数据看板」（不做预测）

涨停池 / 炸板池 / 连板高度 / 龙虎榜（净买 + 机构）/ 资金流 / 板块热力。

**这些是数据不是预测，100% 可靠**，价值是省时间。保留但降级为辅助。

---

### 3.3 必须砍掉或降级的功能

| 功能 | 处理 | 理由 |
|---|---|---|
| **三档预测（超短/波段/长线）的 5 日 entry/stop/target** | **砍掉**，改为 T+1 规则 | 数据证明 5 日持有为负 |
| **1500 只大名单** | 降级为"候选池"，默认折叠 | 无决策价值 |
| **`rank_score` 排序** | **暂停使用**，直到用正确口径重训并验证 | 样本外比随机差 |
| **麦唛 Q5/Q4 宣称的"回测胜率 72.9%/57.6%"** | 改为**实盘验证值 + 样本量** | 实盘 7 次：28%/72%/100%(n=1)/33%(n=3)/65%/100%(n=8)/62% |
| **回测 tab（前端算的龙头战法）** | 砍掉，合并进"信号可信度" | 口径与实盘不一致，误导 |
| **7 个平级 tab** | 收敛为 4 个 | 见 3.4 |

### 3.4 信息架构：7 tab → 4 tab

```
  🎯 决策          📊 市场          📈 复盘          👤 我的
  ├ 今日决策卡      ├ 情绪(涨停/炸板)  ├ 超额曲线        ├ 持仓管家
  ├ 交易清单        ├ 龙虎榜          ├ 信号可信度      ├ 交易日志
  ├ 买入检查清单     ├ 资金流          ├ 模拟账户        ├ 我的胜率
  └ 候选池(折叠)     └ RSI扫描         └ 我的vs系统      └ 设置
```

**个股页**：从任意列表点进去的全屏工作台
- K 线（买卖点标注在图上）+ 分时
- 信号面板（正负分色 + 样本量）
- 买入检查清单（实时判定）
- 我的历史交易记录（如果持有过）

## 四、实施优先级

| 阶段 | 功能 | 工期 | 上线即可验证 |
|---|---|---|---|
| **P0** | 信号口径修正（T+1/T+5 重训权重）+ 信号正负展示 | 2 天 | 前 8 只 vs 全池 T+1 对比 |
| **P0** | 入场可行性预警（27% 买不到） | 1 天 | 预警命中率 |
| **P1** | 今日决策卡（含"建议观望"） | 2 天 | 建议与实际 α 方向一致性 |
| **P1** | 交易清单（3~8 只 + 可成交价 + 到期提醒） | 3 天 | 前 8 只 ≥ 全池 +0.1% |
| **P2** | 持仓管家（止损/目标/动作建议） | 3 天 | 止损执行率 |
| **P2** | 交易日志 + 我的胜率 | 4 天 | 能按信号拆解个人胜率 |
| **P3** | 买入检查清单 | 2 天 | 5 项判定 |
| **P3** | 信号可信度看板（正负分色 + 样本量） | 1 天 | — |
| — | 砍掉：5 日 stop/target、回测 tab、大名单默认展开 | 1 天 | 无功能丢失（改为折叠/替代） |

**合计约 19 天。**

## 五、每个新功能的"可证伪"标准

我不想再做一个"看起来有用"的功能。每个功能上线前必须定好**怎么证明它没用**：

| 功能 | 判定它有效的标准 | 判定它无效的标准 |
|---|---|---|
| 信号口径修正 | 前 8 只 T+1 ≥ 全池 +0.1%，连续 20 日 | 跑不赢全池 |
| 入场可行性预警 | 预警的股票中 ≥60% 次日确实跳空 >+2% | < 40% |
| 今日决策卡 | 说"观望"的日子 α 中位数 < 说"可做"的日子 | 无差别 |
| 交易清单 | 前 8 只跑赢中证 500 | 跑输 |
| 持仓管家 | 用户止损执行率提升 | 无变化（需埋点） |
| 交易日志 | 用户能说出自己最差信号 | 用不起来 |

**如果某个功能 20 个交易日内达不到标准，就下线，而不是继续加参数。**

---

## 六、一句话总结

> **现在这个工具的问题是：它在努力把"选股"做得更好，但数据说选股这条路本身没有优势。
> 真正能提升你收益的是：知道自己该不该做（环境）、能不能买到（可行性）、
> 什么时候必须走（纪律）、以及你实际做得怎么样（复盘）。
> 这四件事，工具现在一件都没做好。**

## 附：全部实测数据出处

| 结论 | 数据规模 | 方法 |
|---|---|---|
| 日内 α ≈ 0 | 14 个交易日 × ~1,100 只 | 池子次日开盘→收盘 vs 全市场同口径 |
| 持有期 T+1 最优 | 15 天样本外 × 5 个持有期 | 次日开盘买入 → 第 N 日收盘 |
| 排序比随机差 | 15 天样本外 × 前10/20/50/全池 | 每日取前 N，持有 5 天 |
| 信号口径符号相反 | 24 天 / 26,000+ 次触发 × 14 个信号 | 三种 horizon 对比，相关性 −0.53 |
| 27% 买不到 | 33,027 个候选 | 次日开盘 vs 系统 entry |
| 止损被打掉 66% | 22,709 笔 | 真实 OHLC 逐日判定 |
